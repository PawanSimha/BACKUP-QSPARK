How It Works

Customer journey for smart parking

1

Create an Account

Sign up with your email and set up your wallet balance.

2

Select a Parking Floor and Vehicle Type

Choose a parking floor and vehicle type (bike or car).

3

Choose an Available Slot

Browse real-time available slots and select your preferred spot.

4

Confirm the Booking

Pay using your wallet balance and confirm the booking.

5

Receive the Booking QR Code

Generate your unique booking QR code instantly.

6

Scan at the Gate

Present QR code at entry and exit gates for automated tracking.

Note: Wallet payments are simulated within the QSPARK system — no external payment gateway integration.

Architecture

QSPARK technology stack

Frontend

  • HTML5 & Jinja2 templating
  • Compiled Tailwind CSS
  • Vanilla JavaScript
  • QS & QSUI utility globals

Backend

  • Python Flask application factory
  • Flask-WTF CSRF protection
  • Session-based authentication
  • Parameterized SQL queries

Database

  • SQLite 11-table schema
  • Foreign key enforcement
  • BEGIN IMMEDIATE transactions
  • Audit logging for all financial operations

QR & API

  • /api/qr/scan endpoint
  • Camera-based QR scanning
  • Backend validation
  • RESTful API endpoints

Frequently Asked Questions

QSPARK is a web-based smart parking slot booking and management system. Customers book parking in advance using an internal digital wallet, receive a QR code, and present it at the parking gate. Staff scan the QR code to register vehicle entry and exit.
Customers can browse available parking slots by floor and vehicle type, then reserve a slot using their wallet balance. The booking is confirmed immediately and a QR code is generated for gate entry.
Customers present their booking QR code at the parking gate. Staff scan the QR code to register vehicle entry. At exit, the scan records the exit time and calculates the parking duration against the wallet balance.
Booking cancellation is available through the user dashboard. Cancelled slots are released back to available inventory immediately.
The QSPARK wallet is an internal simulated balance used for booking confirmations. Wallet top-ups are performed by parking staff. No external payment gateway is integrated.
QSPARK has three roles: CUSTOMER (browse and book), ADMIN (manage operations and bookings), and SUPER_ADMIN (system-wide configuration and financial monitoring).
